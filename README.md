# Heat-related climate risk analysis tool · Seville 2050

**Live viewer:** https://j-sola-caraballo.github.io/seville-heat-risk/

Interactive bilingual (Spanish / English) viewer of heat-related climate risk in Seville in 2050, by census tract. It combines heat hazard and socioeconomic vulnerability in a single map.

Based on:
Sola-Caraballo, J., López-Cabeza, V. P., Serrano-Jiménez, A., Rivera-Gomez, C. and Galan-Marin, C. (2026). *A predictive framework for urban climate risk: Mapping heat hazard and socioeconomic vulnerability at high resolution scenarios.* Urban Climate, 70, 103156. https://doi.org/10.1016/j.uclim.2026.103156

Research group: TEP-206 SATH, University of Seville.

This repository only contains the data published in the tool (results by census tract and Cadastre buildings).
